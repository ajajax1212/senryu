# Stitch 用 画面仕様プロンプト集

既存の3枚（タイトル／プレイ／結果）で確立した見た目は活かしつつ、ゲームの構造を正しい仕様に直して一式そろえるための指示文。

## 使い方

1. Stitch で既存プロジェクトを開き、確立済みのテーマ（配色・フォント・角丸・余白）を維持したまま新しい画面を追加する
2. **「A. 共通の前提」を毎回プロンプトの先頭に貼る**。これを省くと前回と同じ勘違い（お題あり・AI採点・ソロプレイ）に戻る
3. その下に「B. 画面別」から1画面ぶんを貼る
4. 出てきた HTML を `docs/mockups/` に保存する

**下ネタデッキの札の文言は Stitch に渡さないこと。** フィルタされる可能性が高く、モックには不要。R18は「トグル」と「確認ダイアログ」の存在だけ表現できればよい。

## A. 共通の前提（毎回先頭に貼る）

```
このアプリは「五七五」という川柳を作るパーティーゲームです。
既存プロジェクトのデザインシステム（配色・タイポグラフィ・和紙テクスチャ・判子ボタン）を
そのまま維持してください。

【前回の生成で間違っていた点。今回は必ず直してください】
1. お題（テーマ）は存在しません。「お題 秋」のような表示を入れないでください。
2. AIやシステムが句を評価しません。「評価 秀作」のような採点表示を入れないでください。
   勝敗は必ず人間が決めます。
3. ソロプレイではありません。3〜8人で同時に遊ぶマルチプレイです。
   「Collection」「次の一句へ」のような一人用の導線は不要です。
4. 俳句ではなく川柳です。季語も切れ字も使いません。
   「古池や蛙飛び込む水の音」のような俳句を例文に使わないでください。
   「や」「かな」「けり」で終わる文言も使わないでください。
5. ナビゲーションの Arena / Collection / Tutorial は不要です。

【ゲームのルール】
・札には5音の言葉か7音の言葉が1つ書かれています。
・手札は必ず「5音札4枚 + 7音札2枚」の合計6枚です。
・5音札2枚と7音札1枚を選んで、上の句(5) / 中の句(7) / 下の句(5) に並べて1句作ります。
・5音札は上の句にも下の句にも置けます。並べ替えで意味が変わるのが面白さの中心です。

【表示のルール】
・札の文字と句は必ず縦書きにしてください。
  CSS は writing-mode: vertical-rl; text-orientation: upright; を使ってください。
  （text-orientation: mixed は使わないでください。「AI絵」「新NISA」のような
   ラテン文字混じりの札が横倒しになって読めなくなります）
・日本語フォントは必ず Noto Serif JP を読み込んでください。
  Noto Serif（JPなし）だと日本語が別のフォントに置き換わります。
・ライトテーマのみ。ダークモードは不要です。
・PCブラウザ（デスクトップ幅）を主、スマホを従として設計してください。

【札の文言はこの中から選んでください（創作しないでください）】
5音札: 残業日 / 会議室 / 部長の目 / 給料日 / 定期券 / 子の寝顔 /
       月明かり / 春の風 / 冬の朝 / 二日酔い / 陰キャ飯 / 既読無視 /
       通知音 / 推しの顔 / 課金勢 / 知らんけど / 草生える / ととのった
7音札: メール返さぬ / 部長が笑う / 定時で帰る / 会議が長い /
       妻に叱られ / 傘を忘れて / 桜が散った / 推ししか勝たん /
       解釈違い / 草も生えない / 炎上しても / 昨日と同じ

【成立する句の例（例文が必要なときはこれを使ってください）】
・定期券 / 会議が長い / 二日酔い
・子の寝顔 / 炎上しても / 給料日
・春の風 / 推ししか勝たん / 残業日
```

## B. 画面別プロンプト

### 1. タイトル画面（既存を修正）

```
タイトル画面です。既存のタイトル画面をベースに、以下を直してください。

・ナビゲーションの Arena / Collection / Tutorial を削除する。
・ボタンを次の3つにする（文言はそのまま使うこと）:
  「オンラインで遊ぶ」（主ボタン・判子スタイル・朱色）
  「1台をまわして遊ぶ」（副ボタン）
  「遊び方」（テキストリンク）
・「オンラインで遊ぶ」の下に小さく説明:
  「部屋を作ってURLを配る。各自の画面で手札を見るので全員同時に作れる」
・「1台をまわして遊ぶ」の下に小さく説明:
  「スマホ1台を手渡しで回す。手番のたびに手札を隠す」
・縦書きの「五七五」を主タイトルにする。英字サブタイトルは不要。
```

### 2. 参加画面

```
オンライン対戦の入口です。

・見出し「オンラインで遊ぶ」
・入力欄1つ: ラベル「ニックネーム」、プレースホルダ「12文字まで」
・主ボタン「部屋を作る」（判子スタイル）
・区切り線の下に副セクション「部屋コードで参加」
  入力欄: プレースホルダ「はるかぜ-とら-123」
  ボタン「参加する」
・エラー表示の領域を1つ用意する（例: 「このURLの部屋は見つかりませんでした」）
```

### 3. ロビー画面

```
ゲーム開始前の待機画面です。ホストが設定して開始します。

・画面上部に部屋コードを大きく表示（例「はるかぜ-とら-123」）
・招待URLのカード: 「このURLを配れば参加できます」＋ URL文字列 ＋「URLをコピー」ボタン
・参加者一覧のカード: 見出し「参加者（4人）」
  各行に 名前 / ホストには王冠アイコン / 自分には「（あなた）」/ 右端に「接続中」バッジ
  例: タロウ👑（あなた）、ハナコ、ジロウ、サブロウ
  3人未満なら「あと1人必要です」と表示
・モード選択（2択・ラジオのようにどちらか1つ選択状態）:
  「独断と偏見モード」説明「親が好みで一番良い句を選ぶ。全員同時に作れる」
  「コンテストモード」説明「1人ずつ提出し、他の全員が100点満点で採点する」
・使う札の選択（チェックボックス3つ）:
  「標準」5音108枚／7音141枚・常に使用（オフにできない、灰色表示）
  「ネットミーム・流行語」5音118枚／7音107枚
  「下ネタ（大人向け）」R18バッジ付き・既定オフ
・最下部に主ボタン「はじめる」（ホストのみ活性）
・ホスト以外には代わりに「ホストが開始するのを待っています」と表示した状態も作る
```

### 4. R18確認ダイアログ

```
「下ネタ（大人向け）」をオンにしたときだけ出るモーダルです。

・見出し「下ネタデッキを入れますか」
・本文「身体・行為・夜の街・修羅場を扱う直球の札が222枚入ります。
  同席する全員が了承しているか確認してください。」
・主ボタン「全員OK。入れる」
・副ボタン「やめておく」
・具体的な札の文言は一切表示しないでください。
```

### 5. 手番画面（作句）★最重要

```
自分の手番で句を組み立てる、このゲームの中心画面です。

【上部】
・残り時間バー（横長・「残り 4:32」の表記・残り30秒で朱色に変わる状態も作る）
・見出し「ハナコ の手番」、右に「交換 残り2回」のバッジ
・タブ2つ「句を作る」（選択中）/「札を交換する」

【中央：句のスロット】
・縦書きの札を3枚横に並べる領域。右から左に 上の句 → 中の句 → 下の句 の順。
  （縦書きなので右が先頭）
・各スロットの上に大きく薄く「五」「七」「五」のラベル
・中の句のスロットだけ縦に長い（7音なので）
・空のスロットは破線の枠、埋まったスロットは白地に濃紺の枠の札
・埋まっている例: 上の句「定期券」/ 中の句「会議が長い」/ 下の句 は空
・スロットの下に「↕ 上句と下句を入れ替える」ボタン

【下部：手札】
・見出し「手札」
・5音札4枚を1行、7音札2枚をその下に1行。すべて縦書き。
  7音札は5音札より縦に長くして、音数が一目で分かるようにする。
・5音札の例: 残業日 / 部長の目 / 月明かり / 二日酔い
・7音札の例: メール返さぬ / 会議が長い
・句に使用中の札は選択状態（枠が朱色）にする

【最下部】
・主ボタン「この句で提出する」（判子スタイル・3枚そろうまで非活性）
・小さく「親（タロウ）が選びます」
```

### 6. 手番画面（交換タブ）

```
手番画面の「札を交換する」タブを開いた状態です。レイアウトは画面5と共通。

・説明文「いらない札をタップして交換する。捨てた札は全員に公開され、他の人が拾えます」
・手札6枚は同じ配置。捨てる札として選んだものは半透明＋朱色の破線枠にする
・その下に「捨て場」のパネル
  見出し「捨て場（あと5音1枚・7音0枚まで拾える）」
  捨てられた札を縦書きで並べ、各札の下に小さく「ジロウ が捨てた」と誰が捨てたか表示
  拾う対象に選んだ札は選択状態にする
・最下部の主ボタン「2枚を交換する（うち1枚は捨て場から）」
```

### 7. 提出後の待機画面

```
自分は提出済みで、他の人を待っている状態です。

・見出し「提出しました」
・自分が出した句を縦書きの札3枚で大きく表示
  例: 定期券 / 会議が長い / 二日酔い
・その下のパネル: 見出し「まだ詠んでいる人」＋ 名前を並べる（例「ジロウ、サブロウ」）
・全員そろったら見出しが「全員そろいました」に変わる状態も作る

もう1パターン、独断と偏見モードの親用も作ってください:
・見出し「あなたが親です」
・説明「句は作りません。出そろったら好きな1句を選んでください。」
・自分の句は表示せず、待っている人の一覧だけ出す
```

### 8. 審査画面（独断と偏見モード）★重要

```
親が全員の句から1句を選ぶ画面です。このモードの山場なので見栄えを重視してください。

・残り時間バー（「残り 1:48」）
・見出し「タロウ の独断と偏見」
・説明「一番良かった句をタップして選んでください。理由は要りません。好みで決めてください。」
・句を3〜4句、縦書きの大きなカードで並べる。
  カードは和紙のような質感、濃紺の枠、押せることが分かるホバー状態を作る。
  **作者名は絶対に表示しないでください。** 誰の句か分からないことが重要です。
  例:
    定期券 / 会議が長い / 二日酔い
    子の寝顔 / 炎上しても / 給料日
    春の風 / 推ししか勝たん / 残業日
・デスクトップでは横に並べ、狭いときは縦に積む

親以外が見る待機バージョンも作ってください:
・見出し「タロウ が選んでいます」
・説明「全員の句が出そろいました。親の独断と偏見をお待ちください。」
・同じ句が並ぶが、押せない見た目にする
```

### 9. 採点画面（コンテストモード）

```
提出された1句に0〜100点を付ける画面です。

・残り時間バー
・見出し「ハナコ の採点」
・句を縦書きの大きなカードで1つだけ表示。カードの下に「タロウ の句」と作者名を出す
  （このモードでは作者は分かっていてよい）
・点数の大きな数字表示（例「50」）。金色〜朱色系で目立たせる
・0〜100のスライダー
・クイック入力ボタン5つ: 0 / 25 / 50 / 75 / 100
・主ボタン「50点で確定する」（判子スタイル）
・小さく「他の人の点数は全員が入れ終わるまで見えません」

採点済みの待機バージョンも作ってください:
・見出し「80点を入れました」
・「まだ入れていない人: ジロウ、サブロウ」
```

### 10. ラウンド結果（独断と偏見モード）

```
親が選んだ句を発表する画面です。

・見出し「第1ラウンド 結果」
・「タロウ が選んだのは」
・選ばれた句を縦書きの大きなカードで表示。今度は作者名を出す。
  カードに朱色の判子スタンプを斜めに重ねる（文字は「一番」）
  カードの下に「ハナコ ＋1ポイント」
・その下に小さめの見出し「選ばれなかった句」
  残りの句を小さめのカードで並べ、それぞれに作者名を添える
・最下部に主ボタン「第2ラウンドへ」（ホストのみ）
・ホスト以外用に「ホストが次に進めるのを待っています」の状態も作る
```

### 11. ラウンド結果（コンテストモード）

```
採点の集計を発表する画面です。

・見出し「第1ラウンド 結果」
・句を縦書きのカードで表示、下に作者名「タロウ」
・平均点を大きく表示（例「63.3」）＋ 小さく「平均点」
・その下に採点の内訳を表で:
   ハナコ 80点 / ジロウ 60点 / サブロウ 50点
・最下部に主ボタン「第2ラウンドへ」（ホストのみ）
```

### 12. 総合結果画面

```
全ラウンド終了後の最終順位です。

・見出し「総合結果」を縦書きで大きく
・順位表:
   1位（★）ハナコ 2勝
   2位 ジロウ 1勝
   3位 タロウ 0勝
   4位 サブロウ 0勝
  1位の行は朱色か金色で強調し、判子スタンプを添える
・「ハナコ の勝ち」と大きく
・同率のときは「同率優勝」と出す状態も作る
・主ボタン「もう一度遊ぶ」
・副ボタン「タイトルへ」

コンテストモードでは列見出しが「平均点」になり、値が「63.3点」のような小数になります。
その版も作ってください。
```

### 13. 手番引き継ぎ画面（1台をまわす版のみ）

```
スマホ1台を回して遊ぶときに、手番と手番の間に挟む仕切りです。
次の人が受け取るまで手札を隠しておくための暗幕なので、情報は最小限にします。

・画面中央に「第1ラウンド ／ 全4ラウンド」と小さく
・その下に名前を非常に大きく「ハナコ」
・「さんに端末を渡してください」
・役割を1行「句を作ります」（審査のときは「審査します」、採点のときは「採点します」）
・主ボタン「ハナコです」（判子スタイル）
・最下部に「他の人は画面を見ないこと」
・手札やゲームの情報は一切表示しないでください。
・スマホ縦画面を主として設計してください。
```

## C. できたHTMLを受け取ったあとの作業

Stitch の出力をそのまま本番に使うことはできない。移植時に必ず直すもの。

| 問題 | 対処 |
|---|---|
| 画像が `lh3.googleusercontent.com/aida-public/...` を指している | Stitch の一時ストレージなので消える。ローカルに落とすかCSSで作る |
| `cdn.tailwindcss.com` を読んでいる | 開発用CDN。本番不可。うちは素のCSSなので**カラートークンをCSS変数に写す**のが早い |
| フォントが `Noto Serif`（JPなし）のことがある | 必ず `Noto Serif JP` に直す |
| 縦書きが `text-orientation: mixed` になっていることがある | `upright` に直す（検証済み。[vertical-test.html](vertical-test.html) 参照） |

### 引き継ぐデザイントークン

```
primary            #000666   濃紺。枠線・見出し・札の文字
secondary          #b51a1b   朱。判子ボタン・強調・スタンプ
background         #fbf8ff
surface            #fbf8ff
surface-container-lowest #ffffff   札の地色
surface-container-low    #f5f2fb   パネル
outline            #767683   破線の枠（空スロット）
outline-variant    #c6c5d4   区切り線
on-surface         #1b1b21   本文
on-surface-variant #454652   補助テキスト

角丸  0（既定 0.125rem）— 判子・木版のイメージなので原則角丸なし
影    2px 2px 0 0 rgba(0,6,102,.15)   通常
      4px 4px 0 0 rgba(181,26,27,.3)  判子ボタン
押下  translateY(2px) して影を消す

フォント  Noto Serif JP（句・札・見出し） / Work Sans（UIラベル・ボタン）
```
